# StefanAlMare

### Hardware · macOS · Linux · Reverse Engineering · Open Source

**Understanding how systems work, fixing what does not work, and keeping useful hardware alive.**

---

I enjoy investigating difficult hardware/software interactions, reverse engineering undocumented behaviour, restoring compatibility on modern operating systems, and turning working experiments into reproducible open-source projects.

My work is usually hands-on: real hardware, diagnostics, firmware, USB/PCIe devices, ACPI, drivers, networking, macOS/Hackintosh, Linux and the edge cases where the normal documentation stops being enough.

## ⭐ Featured projects

### 📡 [macOS-Cellular-EM7455](https://github.com/StefanAlMare/macOS-Cellular-EM7455)
User-space **MBIM/NCM cellular networking for modern macOS** using the Sierra Wireless EM7455 / Dell DW5811e. Includes Cellular.app, automatic Ethernet/Wi-Fi fallback, APN handling, signal telemetry, a macOS `.pkg` installer and the complete reverse-engineering history.

### 🖱️ [VoodooPS2-FocalTech](https://github.com/StefanAlMare/VoodooPS2-FocalTech)
Reverse-engineering and compatibility work around **FocalTech PS/2 touchpads on macOS**, with the goal of bringing unsupported laptop hardware closer to native Mac trackpad behaviour.
