## Permanent division of responsibility
Everything technically executable in GitHub is executed there by the assistant. This includes:
- offline/static validation;
- source and workflow authoring/integration;
- compile/diff;
- build/package;
- packaged-application audit;
- SHA/identity manifest generation and verification;
- artifact publication;
- workflow monitoring and complete log/artifact audit;
- persistence of decisive results.

The user is not asked to compile, build or package locally. A GitHub workflow failure is repaired and rerun by the assistant rather than shifted to the user. If GitHub execution is genuinely impossible because a required capability, input or runner is unavailable, work stops and the exact blocker is recorded. Local compilation requires an explicit user override and is never the default fallback.

The user runs only minimal identity-pinned actions that inherently require real ASUS2 state:
- live cache/file/log/hardware inspection;
- exact installed-state and fresh-process provenance;
- privileged artifact backup/deploy to `/Applications/OpenCore-Patcher.app` when required;
- opening OCLP;
- manual Root Patch only after explicit assistant authorization;
- accelerated boot, VESA recovery, power cycling and manual boot selection.

A printed PASS is never sufficient. The assistant audits complete GitHub and target-local outputs before authorizing the next boundary.

## Split FASTLANE contract
GitHub/assistant lane:
`validate -> integrate -> compile/diff -> build/package -> packaged audit -> SHA/manifest -> publish artifact -> assistant full audit/persist`.

Target-local ASUS2/user lane, only when required:
`pin repository/branch/workflow run/head/artifact -> download/verify -> backup/deploy -> fresh-process/live-state proof -> open OCLP -> STOP`.

Only after complete audit may the user manually Root Patch. Root Patch output is then audited before any accelerated boot is authorized. Automatic Root Patch and reboot remain forbidden.

For each applicable GitHub build, persistence must include repository, branch, workflow, run/job, runner, head SHA, artifact ID/digest, inner artifact SHA, packaged executable SHA and packaged audit result.

Historical checkpoints remain immutable records of the workflow used at their time. Their wording that the user runs a full compile/build FASTLANE is superseded prospectively by this permanent contract.
